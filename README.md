# Recursion Basics in Java

## Overview

This project demonstrates the basics of recursion in Java. It includes a simple program that prints numbers from 1 to N using recursive function calls.

* A **Base Case** to stop recursion.
* A **Recursive Call** to continue the process.

## Program: Print 1 to N Using Recursion

### Code Logic

1. Start with the number 1.
2. Print the current number.
3. Call the same method with the next number (`n + 1`).
4. Stop when the number exceeds the specified limit.


## Concepts Learned

* Recursive functions
* Base case
* Recursive calls
* Call stack
* Difference between recursion and iteration
